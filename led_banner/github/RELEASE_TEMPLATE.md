# NYBanner v{ВЕРСИЯ} — приложение для управления новогодней LED-лентой

Приложение для Android (5.0+), которое отправляет текст, бегущие строки и клипы
на ленту 8×96 на ESP32 по Wi-Fi и Bluetooth. Работает в связке с прошивкой `firmware_esp32`.

## Что нового
- ✍️ Мини-редактор: написал текст → увидел превью 1:1 → отправил на ленту
- 📡 Автопоиск ленты в локальной сети (UDP) + подключение по IP
- 🔵 Bluetooth: устройство ленты ищется как **NY-BANNER**
- 🎞 Очередь клипов с буфером на 5 минут: лента сама запрашивает следующий фрагмент за 5 секунд до конца (нужен включённый ПК-сервер `pc_app` или ссылка на сайт)
- 🌐 Вкладка «Файлы»: скачивание готовых клипов со страницы релизов GitHub

## Установка
1. Скачайте файл **NYBanner-v{ВЕРСИЯ}-release.apk** (см. Assets ниже).
2. Переключите APK на телефон (Telegram / USB / почта).
3. Откройте файл → разрешите установку из «неизвестных источников».
4. Приложение запросит разрешения на Bluetooth и хранение файлов — подтвердите.

SHA-256 APK: `{SHA256}` (файл `.sha256` лежит в Assets для проверки).

## Быстрый старт
1. Прошейте ESP32 (`firmware_esp32`), подключите её к тому же Wi-Fi.
2. Откройте вкладку «Устройства» → «Автопоиск» (или введите IP из монитора последовательного порта).
3. Вкладка «Редактор» → введите текст → «Отправить на ленту».

## Требования
- Android 5.0 (API 21) и выше
- Для Wi-Fi-управления — телефон и лента в одной сети
