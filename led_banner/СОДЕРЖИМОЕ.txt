NYBanner v3.2 — новогодняя LED-лента (ESP32 + 3 панели 8x32)
=============================================================

ЧТО В АРХИВЕ:

1. pc_app\  — программа для ПК v3.2 (3 режима: блоки Scratch / редактор / прямой код)
   • build_exe.bat      — ДВОЙНОЙ КЛИК на Windows, соберёт NYBanner_PC.exe.
                          ИСПРАВЛЕНА ОШИБКА "pyinstaller не является командой":
                          теперь вызов идёт через "python -m PyInstaller" и папка
                          Roaming\Python\Scripts больше не обязана быть в PATH.
                          Работает от F:\pc_app (и из любой другой папки).
   • start.bat          — НОВОЕ: запуск программы СРАЗУ через Python, без сборки exe.
                          Если с exe проблемы — просто пользуйтесь start.bat.
   • README_Windows.txt — пошаговое объяснение ошибок и решений.

2. esp32_web\index.html — САЙТ №2: панель управления лентой из браузера.
   Вход БЕЗ PIN-кода кнопкой «Войти» (PIN теперь опционален), либо по коду.

3. site\index.html      — САЙТ №1: витрина скачивания APK / EXE / прошивки,
   современные ссылки на onlyfiles.com.

4. firmware_esp32\      — прошивка ESP32 v3.0+ (открыть .ino в Arduino IDE).
   PIN по умолчанию выключен (0000 = открытый доступ), команда "PIN 1234" включает.

5. android\             — исходники Android v3.2 (versionCode 5).
6. NYBanner-debug.apk / NYBanner-release.apk — готовые приложения.

ЕСЛИ ЧТО-ТО НЕ ЗАПУСКАЕТСЯ: сначала пробуйте start.bat (ПК) или сайт esp32_web
(управление лентой вообще без установки программ).
