NYBanner — новогодняя LED-лента (ESP32 + 3 панели 8x32)
========================================================

vsy.444.zip содержит:

1. esp32_web/index.html   — САЙТ №2: панель управления лентой прямо из браузера.
   Откройте файл, введите PIN (его лента показывает при включении), и можно:
   писать текст, выбирать эффект, собирать программу Scratch-блоками,
   менять яркость, настраивать Wi-Fi ленты, жать «Сбросить панель» (новый PIN).

2. site/index.html        — САЙТ №1: витрина для скачивания APK / EXE / прошивки.

3. pc_app/nybanner_pc.py  — программа для ПК v3.0 (3 режима: блоки/редактор/код).
   pc_app/build_exe.bat    — ДВОЙНОЙ КЛИК на Windows = соберёт NYBanner_PC.exe
                             (нужен установленный Python 3 с галочкой "Add to PATH").

4. firmware_esp32/        — прошивка ESP32 v3.0 (открыть newyear_banner.ino в Arduino IDE).
5. android/               — исходники Android-приложения v3.0 (Android Studio).
6. NYBanner-debug.apk     — готовое приложение на телефон (ставить сразу).
7. NYBanner-release.apk   — подписанная версия для RuStore.
8. github/KAK_ZALIT_APK.md— как выложить файлы на GitHub Releases (без рекламы).

Быстрый старт: зашейте прошивку -> включите -> на ленте появится PIN ->
откройте esp32_web/index.html -> введите PIN -> управляйте.
