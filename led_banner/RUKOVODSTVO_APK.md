# Готовые APK — «NYBanner» (управление новогодней LED-лентой 8×96 на ESP32)

## Файлы
| Файл | Для чего |
|---|---|
| `NYBanner-debug.apk` (6.6 МБ) | Личное использование: ставится на любой телефон сразу |
| `NYBanner-release.apk` (5.4 МБ) | Публикация в RuStore (подписан release-ключом) |
| `android/nybanner-release.keystore` | Ключ подписи (пароль: `nybanner123`) — **сохраните его!** |

## Установка на телефон (debug)
1. Перекиньте `NYBanner-debug.apk` на телефон (USB / мейл / Telegram).
2. На телефоне: «Настройки → Безопасность → установка из неизвестных источников» для браузера/файлового менеджера.
3. Откройте APK → «Установить». Всё, приложение «NYBanner» на рабочем столе.

## Что умеет
- **Редактор** — пишете текст, выбираете эффект (бегущая строка / снег / fireworks / шапка), скорость → сразу «Отправить на ленту». Живое превью 1:1 как на панелях.
- **Устройства** — автопоиск ленты по Wi-Fi (UDP), ручной IP, либо Bluetooth (устройство `NY-BANNER`).
- **Файлы** — сайт для скачивания готовых клипов/плейлистов; JSON-плейлист загружается прямо на ESP32 (её буфер на 5 минут + докачка за 5 сек до конца работает именно так, как вы просили).
- Требования: Android 5.0+, экран с Wi-Fi или Bluetooth.

## Публикация в RuStore
1. Зарегистрируйтесь на https://rustore.ru (нужен аккаунт разработчика, бесплатно для физлиц).
2. «Добавить приложение» → загрузите `NYBanner-release.apk`.
3. Метаданные (название, описание, скриншоты) — в папке `android/fastlane/metadata/android/`, оттуда можно копировать текст.
4. Скриншоты: запустите приложение на телефоне, сделайте 2–4 снимка экранов Редактора и Устройств, загрузите (минимум 1, формат PNG/JPG).
5. Важно: если будете выпускать обновления — подписывайте их **тем же keystore-файлом**, иначе RuStore не примет апдейт. Храните `nybanner-release.keystore` и пароль в надёжном месте.
6. Для продажи/донижатов RuStore подключает внутреннюю биллинговую систему отдельно (раздел «Монетизация» в консоли разработчика).

## Пересборка после правок кода
```bash
cd led_banner/android
ANDROID_HOME=/opt/android-sdk gradle assembleDebug assembleRelease --no-daemon
```

## Предупреждение
Ключ подписи в этом проекте — временный (сгенерирован автоматически, пароль `nybanner123`).
Перед реальной публикацией рекомендуется создать свой:
```bash
keytool -genkey -v -keystore moy_keystore.keystore -alias nybanner -keyalg RSA -keysize 2048 -validity 10000
```
и подставить путь/пароли в `android/app/build.gradle` (блок signingConfigs.release).
